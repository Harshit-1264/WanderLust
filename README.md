# 🌍 WanderLust

WanderLust is a travel web application built using Node.js, Express.js, and MongoDB that allows users to discover, create, edit, and delete travel destinations. It’s a full-stack CRUD application focused on seamless user experience and simple yet functional UI.

## 🛠 Tech Stack

- **Frontend**: HTML, CSS, Bootstrap, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Templating Engine**: EJS
- **Other Tools**: Mongoose, Method-Override, Express Router

## ✨ Features

- 🗺️ View all travel destinations
- ➕ Add new travel spots with title, location, price, and description
- 📝 Edit existing destinations
- ❌ Delete destinations
- 📷 Image support for locations (via URL)
- 📄 RESTful routing structure
- 💾 Persistent data with MongoDB
